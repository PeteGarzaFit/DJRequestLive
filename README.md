# DJ Request Live — MVP

Multi-tenant DJ request platform.

## MVP stack
- React + Vite PWA frontend
- Node.js + Express API
- MySQL database (Hostinger)
- Stripe planned for subscriptions / paid boosts
- QR codes generated per event

## MVP flow
DJ signup → DJ profile → create event → QR code → guest request → DJ approve/reject → mark played.
